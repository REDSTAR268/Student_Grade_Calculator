# 🎓 Student Grade Calculator

A beginner-friendly web application that calculates a student's academic results using JavaScript. Students can enter their name and five subject scores to see their total score, average, highest score, lowest score, letter grade, and pass/fail status.

## ✨ Features

- Enter the student's name.
- Enter scores for five subjects:
  - Mathematics
  - English
  - Science
  - Computer Studies
  - Social Studies
- Calculate the total score out of 500.
- Calculate the average score out of 100.
- Display the highest and lowest scores.
- Assign a letter grade from A to F.
- Display a Pass or Fail result.
- Validate missing or invalid inputs.
- Reset the form and results.
- Switch between Light Mode and Dark Mode.
- Responsive layout for smaller screens.

## 🛠️ Technologies Used

- **HTML5** — Structures the webpage and input form.
- **CSS3** — Styles the interface and provides responsive design and theme styles.
- **JavaScript** — Validates inputs, performs calculations, assigns grades, and updates the results.

## 📊 Grading System

| Average Score | Grade | Result |
|---|---|---|
| 80–100 | A | Pass |
| 70–79.99 | B | Pass |
| 60–69.99 | C | Pass |
| 50–59.99 | D | Pass |
| Below 50 | F | Fail |

**Note:** A student passes when the average score is at least 50.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a web browser, or use the Live Server extension.
4. Enter a student's name and all five subject scores.
5. Click **Calculate Grade** to display the results.
6. Try the Reset button and switch between Light Mode and Dark Mode.

## 🧪 Testing

The project has been tested for the following cases:

- Valid name and subject scores.
- Empty student name.
- Missing subject scores.
- Scores outside the allowed range of 0–100.
- Resetting the form and results.
- Switching between Light Mode and Dark Mode.

All six tests worked correctly during testing.
